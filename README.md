# 墨序

Chrome Manifest V3 助手扩展，支持原生 AI 侧栏、多轮对话、联网搜索与来源引用、网页和 PDF 阅读、本地文件分析、写作改写，以及网页双语、划词翻译和侧边悬浮球。默认对接 USTC「词元计划」，也支持 Chat Completions 兼容 API。

当前版本：**0.5.6**。

## 当前版本 · 界面与阅读排版

侧栏回答采用标准 Markdown 与本地 KaTeX 排版，支持行内、独立、多行和矩阵公式。侧栏、弹窗和设置界面与回答统一字体；中英文按字符范围独立选用本机 Hiragino Sans GB 与 Optima，公式使用 KaTeX 数学字体；长公式可横向滚动。

支持 Exa 联网搜索、公开网页与 PDF 链接读取，以及 PDF、TXT、LOG、Markdown、CSV、JSON 文件附件。联网按钮和文件按钮位于输入区，模式选择、翻译、导出与设置收进右上角“···”菜单。侧栏保留象牙白、暖灰和石墨黑外观，输入框默认单行并可拖动调节高度；原安装路径和服务配置继续沿用。

## AI 侧栏

输入框默认单行。拖动输入框上沿细线调节高度，尺寸保存在本机；双击恢复自动展开。键盘聚焦细线后可用上下方向键调节，Enter 恢复自动。

点击工具栏墨序图标 → **打开 AI 助手侧栏**。原来的网页翻译入口仍在弹窗和悬浮球面板中。

- 多轮对话与流式回答，支持停止、复制、重试和安全 Markdown 排版。
- 快捷任务涵盖网页总结、论文解读、概念解释、翻译、润色改写和写作。
- 网页内容由用户主动附加，页面卡片展示来源；切换网页会解除旧页面附加，发送前再次检查。普通聊天不会自动抓取或发送页面正文。
- 正文提取排除表单、输入框、编辑区、隐藏内容和插件界面，保留可见参考链接的文字；最长 24,000 字符，超长时明确标记为摘录。URL 的查询参数与锚点不随附加内容发送。
- 模型可单次切换，也可读取服务提供的模型列表；不更改网页翻译所用模型。
- 对话历史保存在本机，支持新对话、继续历史对话与 Markdown 导出。关闭侧栏前可点击停止结束正在生成的请求。
- 服务设置支持 USTC、DeepSeek、OpenAI、本机 Ollama 及 Chat Completions 兼容接口；可保存 12 个本机服务档案，载入后点击“保存并授权”启用。API 密钥保留在可信扩展存储中。

网页访问沿用 `activeTab` 与用户已授予的网站权限。如果切换到新网站后提示无法读取，请在该页面点击工具栏墨序图标再打开侧栏。侧栏新增的 `sidePanel` 权限用于 Chrome 原生侧栏，不自动授予所有网站访问权限。

### Markdown 与数学公式

- 使用本地打包的 Markdown-It 排版标题、列表、引用、链接、表格与代码；原始 HTML 不执行，回答中的远程图片不自动加载。
- 使用本地 KaTeX 与随包数学字体渲染公式，无需访问外部公式服务或字体网站。支持 `$...$`、`\(...\)` 行内公式，以及 `$$...$$`、`\[...\]` 独立公式。
- 支持 KaTeX 可识别的分数、上下标、积分、矩阵、分段函数和多行对齐公式；不支持的命令或格式保留原文，不承诺兼容所有 LaTeX 宏包。
- 行内代码和代码块中的公式符号保持原文。流式输出中的公式尚未闭合时先显示原文，闭合后再排版；复制回答和 Markdown 导出保留原始公式文本。
- 长公式在自身区域内横向滚动，避免撑宽侧栏。回答正文和标题采用 Hiragino Sans GB（中文）与 Optima（英文），数学表达式使用 KaTeX 数学字体，代码采用等宽字体。

### 联网搜索

- 输入区的地球按钮控制联网，默认开启并记住本机选择；首次使用需要允许访问搜索服务。
- 使用 Exa 的免密钥搜索入口，无需另填搜索 API 密钥。联网开启时，事实查询和研究问题可触发搜索；已有网页、链接或文件时，明确提出搜索要求才额外搜索。普通续问、问候、写作和编码不会自动搜索；“不要联网”等明确要求优先。
- 实际检索结果提供给模型，并显示可点击的编号来源。搜索摘要是资料摘录，不代表已经阅读每个结果的全文。
- 免费入口受服务商频率限制与网络可用性影响；失败、超时或限流会显示具体提示，不用模型生成的文字冒充搜索结果。

### 链接与本地文件

- 在提问中粘贴公开 HTTP(S) 网页或 PDF 直链，发送时授权对应网站，扩展直接下载并读取正文。文件与链接合计最多 4 份资料，超过上限会明确提示。
- 已读链接留在本次对话的附件列表中，可以连续追问、交叉对比或移除；再次发送同一链接会重新读取。新建、切换或重新打开对话后，需要重新附加资料，历史记录只保留标题与回答，不保存附件原文。
- 点击文件按钮，或把文件拖入输入区，添加 PDF、TXT、LOG、MD/Markdown、CSV、JSON。文本文件支持 UTF-8 和带 BOM 的 UTF-16；CSV、JSON 按原始文本阅读，不执行公式或脚本。
- PDF 使用随扩展打包的官方 PDF.js 在本机提取文字。普通网页的“附加网页”读取当前页面；已打开的公开 `.pdf` 链接可通过该入口下载解析。
- 每个文件或下载文档最多 **20 MB**；PDF 最多解析前 **80 页**，单份资料最多提取 **48,000 字符**。同一提问的文件和链接**共享 48,000 字符**，当前按资料数量平均分配额度，超出部分标记为截取内容。“附加网页”入口另有 24,000 字符上限，包括从该入口附加的 PDF。
- PDF 仅支持可提取的文字层，不包含 OCR。扫描件会提示先做文字识别，密码保护文件需先在本机解锁；图表、公式和多栏排版的文字顺序可能不完整，分析时仍需对照原文。
- 链接读取不携带网站登录 Cookie，也不跟随重定向。登录页、验证码、付费内容、需要跳转的地址、含私密访问参数的链接和内网地址可能无法读取。可改用最终公开直链、打开页面后附加可见正文，或下载文件后导入。依赖网页脚本生成的正文也可能需要“附加网页”。

当前不包含图片识别、视频字幕或语音输入。回答依据实际提供的正文和搜索摘录，不宣称读取未取得的全文。

## 双语与划词翻译

- 保留原文，在段落后显示译文；结合标题、相邻段落、内容领域和术语表翻译。
- 段落进入视口后排队，支持动态加载内容和恢复原文。
- 划词翻译：选中文字后点击旁边的“译”，译文卡片出现在所选段落下方。跨段选择显示在最后一个所选段落下方，列表和表格内保持原有结构。
- 译文卡片支持复制、失败重试和单独关闭；已完成的多条译文可保留对照，连续翻译会取消上一条未完成请求。最多保留 40 条卡片。
- 右键“用墨序翻译所选文字”、扩展弹窗、网页面板与 `Alt + Shift + S` 均支持翻译选区，快捷键无需预先加载内容脚本。
- 网页翻译可暂停／继续，暂停保留已译内容，当前请求完成后停止排队。恢复原文会同时移除网页译文和选区卡片。
- 侧边“译”球：点击打开翻译面板，上下拖动调整位置。
- 默认同时翻译 2 段、请求启动间隔 1 秒，支持 1–4 个并行请求及 0–30 秒启动间隔；多个标签页共用并发和限流队列。
- 默认流式显示，模型生成时就能看到译文；默认单次最长等待 120 秒，可调至 180 秒。超时不自动重复长时间请求，支持手动重试。
- HTTP 429 自动冷却，优先遵守 `Retry-After`；无指定时间时从 30 秒开始退避。限流后提高请求间隔，默认 1 → 2 → 4 秒；连续成功后逐步恢复。
- 最多自动恢复 3 次，明确额度不足时停止自动重试。恢复原文会取消待处理任务。
- 翻译结果仅在扩展会话内缓存；冷却状态在浏览器会话中保存。

## 安装

1. 从 [Releases](https://github.com/concorde-blade/qingyi-translate/releases/latest) 下载 `qingyi-ustc-0.5.6.zip` 并解压，或克隆此仓库。
2. 打开 Chrome 的 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压后的 **`qingyi-ustc` 文件夹**；如果克隆了仓库，选择其中的 **`src` 文件夹**。
4. 打开扩展的“模型与翻译设置”，填写 API 地址、模型和自己的密钥，点击“保存并授权”。

默认 USTC 接口：`https://api.llm.ustc.edu.cn/v1`。模型名称和访问权限以账户实际授权为准，可在设置中读取模型列表。校外访问可能需要校园网隧道。

安装包不包含个人 API 密钥，首次安装需要填写自己的服务配置。升级现有安装时保留原目录，在扩展管理页重新加载即可。

也可以设置其他 HTTPS 兼容接口；本机服务允许使用 HTTP localhost / 127.0.0.1。

## 使用

- 点击扩展按钮中的“翻译当前网页”，或按 `Alt + Shift + T` 翻译／恢复原文。
- 在扩展弹窗点击“在此网站开启划词与悬浮球”，授权当前网站后，刷新和后续访问均可直接划选。只显示入口，不自动发送翻译请求。再次点击可关闭此网站的入口，也会停止已经打开页面的翻译。
- **选中文字 → 点击选区旁的“译 · 翻译所选文字” → 在原文下方查看译文。** 点击“复制译文”复制结果，右上角 × 只关闭当前这条。
- 单次使用无需开启网站常驻：先选中文字，再右键翻译，或按 `Alt + Shift + S`。若快捷键被占用，可在 Chrome 的扩展快捷键设置中重新分配。
- 点击悬浮球打开面板，选择网页翻译、划词翻译、暂停／继续、重试或恢复原文。划词请求会优先于队列中尚未开始的段落；正在请求的段落和全局限流规则仍然有效。
- 设置中可以关闭划选按钮，保留右键与快捷键入口。卡片支持浅色、深色和窄窗口。
- 撤销网站访问权限会取消该网站的自动注入。
- 默认速度设置为“同时翻译 2 段 / 启动间隔 1 秒 / 最长等待 120 秒 / 边生成边显示”。可在“速度与等待”中调整；并行和流式显示减少排队及看到结果前的等待，不会改变模型自身的生成速度。
- 升级后，旧版 25 秒上限、固定串行和默认 4 秒间隔会自动迁移；密钥、模型、术语表及主动选择的 8–30 秒保守间隔保留。后续手动选择的设置不会再次覆盖。
- 如经常限流，在设置中选择同时翻译 1 段，并将启动间隔改为 4、8、15 或 30 秒。共用同一个 API 密钥的其他应用可能同时占用限额。

## 开发与测试

需要 Node.js 22 或更高版本；打包需要 Python 3。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Linux 上可使用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。

构建输出：`outputs/qingyi-ustc/` 和 `outputs/qingyi-ustc-0.5.6.zip`。普通构建不读取私人设置，也不依赖原版沉浸式翻译文件。更新已加载的同一路径扩展时，在扩展管理页点击重新加载，然后刷新使用中的网页；原有浏览器设置会保留。本机安装目录可用 `node scripts/build.mjs --update-personal` 更新代码，保留原有本机预置配置，并在 `work/installed-backup-*` 生成备份。此参数不将个人配置写入公开压缩包。

浏览器测试使用独立 Chromium 配置和本机模拟 API，不消耗真实翻译额度。PDF 专测使用本地生成的有效文档，验证严格 Manifest V3 安全策略下的本地 Worker、文字与页数限制、扫描件提示和取消。公开论文链接另有真实下载验收，未调用模型生成答案。日常测试使用单独的模拟配置加速运行；性能对比使用真实的 4 秒旧间隔与 1 秒新间隔，发布默认间隔为 1 秒且允许自行调整。

## 数据与权限

- 仓库不包含 API 密钥。普通构建的 `local-settings.js` 为空配置。
- 用户密钥仅存于当前浏览器的扩展本地存储，不进行云同步；该存储不是系统钥匙串。网页内容脚本无权读取密钥。
- 主动翻译时，待翻译内容、页面标题和必要的相邻上下文发送到用户配置的 API。API 服务可能按用量计费。
- 文件先在本机解析；发送提问时，提取出的资料文字和对话一起发送到所选模型服务。原始 PDF 文件不交给第三方文档转换服务。
- 联网搜索把本次提问整理为最多 300 字符的查询发送给 Exa；“它”“这篇”等指代可结合最近一条简短事实问题确定主题，不从附件原文或助手回答中提取搜索词。搜索请求不携带模型 API 密钥或网站登录 Cookie。公开链接由扩展直接访问对应网站；搜索与链接读取各自按需请求网站权限。
- 悬浮球按网站单独授权。手动翻译使用 `activeTab`；扩展使用 `scripting`、`storage` 和 `contextMenus` 支持注入、设置和右键操作。
- `work/`、`outputs/`、本机配置和测试浏览器数据均不纳入 Git。

## 范围与限制

网页双语与划词翻译支持普通 HTTP(S) 页面，不直接注入浏览器内部页面、应用商店或 Chrome 内置 PDF 查看器。PDF 可通过侧栏的公开直链或本地文件入口读取文字。网页正文提取不覆盖图片、视频字幕、跨域内嵌页或网站 Shadow DOM。输入框、编辑区、代码区和隐藏内容不参与翻译；跨越这些区域的选区会提示重新选择。Chrome 自带整页翻译已经改写原文时，应先切回原语言。

选区定位在所选内容所在段落下方，不拆开原文中的链接或行内格式。浏览器已经丢弃原始选区位置时，右键菜单提供的文本仍可在面板中翻译。剪贴板被网站或浏览器限制时，会选中译文并提示使用 `Ctrl / ⌘ + C`。

不支持流式的兼容接口可继续返回完整 JSON；明确拒绝流式参数时自动回退一次，也可在设置中关闭流式。流式中断或输出截断不会作为完整结果缓存。

客户端节流可以降低触发限流的概率，无法改变服务端限额。模型翻译结果仍需按用途核对。

此仓库为独立实现的墨序扩展，沿用清译项目目录与内部标识；不包含其他商业插件的安装包或修改版本。PDF.js 使用 Apache-2.0 许可，Markdown-It 与 KaTeX 使用 MIT 许可；来源与许可文件分别见 `src/vendor/pdfjs/`、`src/vendor/markdown-it/`、`src/vendor/katex/`。

回答正文采用本机 Hiragino Sans GB（中文 W3）与 Optima Regular（英文），中文标题和强调使用 W6，英文使用独立 Bold/Italic 字重。未安装的设备使用系统无衬线备用字体，不随插件分发系统字库。正文 16px，公式与代码保留各自的专用字体。
