# 清译 · 上下文双语翻译

Chrome Manifest V3 翻译扩展，支持网页双语、划词翻译和侧边悬浮球。默认对接 USTC「词元计划」，也支持 Chat Completions 兼容 API。

当前版本：**0.1.2**。

## 功能

- 保留原文，在段落后显示译文；结合标题、相邻段落、内容领域和术语表翻译。
- 段落进入视口后排队，支持动态加载内容和恢复原文。
- 划词翻译：右键菜单，或加载扩展后按 `Alt + Shift + S`。
- 侧边“译”球：点击打开翻译面板，上下拖动调整位置。
- 全局串行请求，默认至少间隔 4 秒；多个标签页共用队列。
- HTTP 429 自动冷却，优先遵守 `Retry-After`；无指定时间时从 30 秒开始退避。限流后提高请求间隔，默认 4 → 8 → 16 秒。
- 最多自动恢复 3 次，明确额度不足时停止自动重试。恢复原文会取消待处理任务。
- 翻译结果仅在扩展会话内缓存；冷却状态在浏览器会话中保存。

## 安装

1. 下载或克隆此仓库。
2. 打开 Chrome 的 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择仓库中的 **`src` 文件夹**。
4. 打开扩展的“模型与翻译设置”，填写 API 地址、模型和自己的密钥，点击“保存并授权”。

默认 USTC 接口：`https://api.llm.ustc.edu.cn/v1`。模型名称和访问权限以账户实际授权为准，可在设置中读取模型列表。校外访问可能需要校园网隧道。

也可以设置其他 HTTPS 兼容接口；本机服务允许使用 HTTP localhost / 127.0.0.1。

## 使用

- 点击扩展按钮中的“翻译当前网页”，或按 `Alt + Shift + T` 翻译／恢复原文。
- 在扩展弹窗点击“在此网站常驻悬浮球”，授权当前网站后，刷新和后续访问都会显示悬浮球。首次显示球不会发送翻译请求。
- 点击悬浮球打开面板，选择网页翻译、划词翻译、重试或恢复原文。
- 撤销网站访问权限会取消该网站的自动注入。
- 如经常限流，在设置中将最小请求间隔改为 8、15 或 30 秒。共用同一个 API 密钥的其他应用可能同时占用限额。

## 开发与测试

需要 Node.js 22 或更高版本；打包需要 Python 3。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Linux 上可使用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。

构建输出：`outputs/qingyi-ustc/` 和 `outputs/qingyi-ustc-0.1.2.zip`。普通构建不读取私人设置，也不依赖原版沉浸式翻译文件。

浏览器测试使用独立 Chromium 配置和本机模拟 API，不消耗真实翻译额度。测试构建会缩短请求间隔以加快执行；发布版本最小间隔为 4 秒。

## 数据与权限

- 仓库不包含 API 密钥。普通构建的 `local-settings.js` 为空配置。
- 用户密钥仅存于当前浏览器的扩展本地存储，不进行云同步；该存储不是系统钥匙串。网页内容脚本无权读取密钥。
- 主动翻译时，待翻译内容、页面标题和必要的相邻上下文发送到用户配置的 API。API 服务可能按用量计费。
- 悬浮球按网站单独授权。手动翻译使用 `activeTab`；扩展使用 `scripting`、`storage` 和 `contextMenus` 支持注入、设置和右键操作。
- `work/`、`outputs/`、本机配置和测试浏览器数据均不纳入 Git。

## 范围与限制

支持普通 HTTP(S) 网页。不支持浏览器内部页面、应用商店、内置 PDF、图片、视频字幕、跨域内嵌页或网站 Shadow DOM 中的正文。Chrome 自带整页翻译已经改写原文时，应先切回原语言。

客户端节流可以降低触发限流的概率，无法改变服务端限额。模型翻译结果仍需按用途核对。

此仓库为独立实现的清译扩展，不包含沉浸式翻译原版安装包或其修改版本。
