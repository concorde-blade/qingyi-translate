设置

01 / AI 服务

默认连接中国科学技术大学「词元计划」，也可切换兼容服务。

保存地址、模型和密钥到此浏览器。载入后点击“保存并授权”启用，不影响术语表和阅读偏好。

USTC 官方地址：https://api.llm.ustc.edu.cn/v1。校外使用请先连接校园网隧道（如 iWAN）。

模型权限以你的 USTC 账号实际授权为准。

填写词元计划 API Key；不是统一身份认证密码。不会同步到云端。

02 / 阅读与准确度

模型会结合语境参考术语表。提示词要求保留数字、单位、否定、引用和原文的不确定表达。

点击后才发送翻译请求，译文显示在所选段落下方，可复制、重试或单独关闭。关闭此入口后仍可用右键菜单和 Alt + Shift + S 翻译。先在扩展弹窗开启当前网站的划词与悬浮球，后续访问即可直接划选。

03 / 速度与等待

不必等整段返回。兼容接口也可返回完整结果；服务不支持流式时可关闭。

默认同时翻译 2 段、请求启动间隔 1 秒，最长等待 120 秒。延长等待可避免过早中断，实际生成速度由模型和网络决定。限流时遵守服务商指定的冷却时间并自动降速，连续成功后逐步恢复速度；超时后提供手动重试，不重复长时间等待。

仅在你主动翻译或发送对话时，将相应文本发送到你配置的 API；主动附加网页后，正文摘录会随问题发送。对话记录和服务档案仅保存在本机。密钥保存在本机 Chrome 扩展存储中（并非系统钥匙串）。API 服务可能按用量计费，数据处理政策以所选服务商为准。
支持普通网页双语与划词翻译；当前版本不含 PDF、图片、视频字幕、跨域内嵌页和网站 Shadow DOM 内容翻译。
