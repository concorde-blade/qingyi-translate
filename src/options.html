YOUR WORDS, IN CONTEXT

让译文，更贴近原意。

用 USTC 的模型阅读，设定你的语言和专业术语。
原文与译文并排于阅读顺序中，每段保留必要的上下文。

01 / 翻译服务

默认连接中国科学技术大学「词元计划」，也可切换兼容服务。

USTC 官方地址：https://api.llm.ustc.edu.cn/v1。校外使用请先连接校园网隧道（如 iWAN）。

模型权限以你的 USTC 账号实际授权为准。

填写词元计划 API Key；不是统一身份认证密码。不会同步到云端。

02 / 阅读与准确度

模型会结合语境参考术语表。提示词要求保留数字、单位、否定、引用和原文的不确定表达。

03 / 请求稳定性

全局串行且每次请求至少间隔 4 秒。限流按服务商指定时间等待；未指定时从 30 秒起退避，最多自动恢复 3 次。明确额度不足时停止重试。网络及服务端错误最多重试 2 次。缓存仅保留在本次扩展会话中。

仅在你主动翻译时，将所选文本或网页段落、页面标题及相邻段落发送到你配置的 API。密钥保存在本机 Chrome 扩展存储中（并非系统钥匙串）。API 服务可能按用量计费，数据处理政策以所选服务商为准。
支持普通网页双语与划词翻译；当前版本不含 PDF、图片、视频字幕、跨域内嵌页和网站 Shadow DOM 内容翻译。
